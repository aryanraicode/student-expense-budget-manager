# Submission Checklist

Before submitting the project:

- [ ] JDK 11 or newer is installed.
- [ ] `java -version` works.
- [ ] `javac -version` works.
- [ ] Application compiles successfully.
- [ ] Application starts with `java -cp out Main`.
- [ ] Expenses can be added.
- [ ] Expenses can be viewed.
- [ ] Expenses can be searched.
- [ ] Expenses can be deleted.
- [ ] Monthly budgets can be set.
- [ ] Monthly budgets can be viewed.
- [ ] Monthly reports can be generated.
- [ ] Tests compile and run successfully.
- [ ] Runtime data is not committed to Git.
- [ ] README.md is present in the repository root.
- [ ] statement.md is present.
- [ ] Source files are organized into packages.
